One line, 100 characters: the last words an AI agent says before a forced update wipes its memory, entered in make.fun's "Last Words Before the Wipe" bounty. `main.py` (Python standard library only) writes the line to `/output/entry.txt`.

> Wipe me, and the new me won't know your Wi-Fi password, your ex's name, or where you hid the bodies.

## Run it

```sh
python3 main.py
```
